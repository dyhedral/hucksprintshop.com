# hucksprintshop.com

The public site for Huck's Print Shop, a Dyhedral LLC venture. Served by
GitHub Pages at https://hucksprintshop.com.

`design-system/tokens.css` is a copy of Topo. The source of truth is the
private design system repo (`adzuci/dyhedral`). To update it, run
`./sync.sh` here, then commit and push.

Rules for this page: under 200 words, nothing that isn't true yet, and no
link to anything that doesn't exist. The request form and operator app live
in `adzuci/hucksprintshop` and get linked here only once they're deployed.
